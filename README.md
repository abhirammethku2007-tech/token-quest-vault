# CertVault

## Digital Certificate Management Platform for Colleges

CertVault is a full-stack web application that streamlines certificate management in educational institutions. It enables students to request certificates online, administrators to review and approve requests, and management to monitor activities through analytics and audit logs.

### Live Demo

https://token-quest-vault.vercel.app

---

## Features

### Student Portal

* Secure authentication
* Request certificates online
* Track request status
* Download approved certificates
* Manage profile information

### Admin Portal

* Review certificate requests
* Approve or reject applications
* Generate digital certificates
* Manage users and records

### Management Portal

* Analytics dashboard
* Audit log monitoring
* Signature key management
* System-wide reporting

### Security & Verification

* Role-based access control
* Secure PDF certificate storage
* QR-code based certificate verification
* Public certificate verification page
* Row Level Security (RLS) policies with Supabase
